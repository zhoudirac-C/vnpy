# P29-T06.6 每日市场复盘 AI 编排验证

日期：2026-05-11

## 验证目标

- 验证 `DailyReviewService.run_preview(run_llm=True)` 会在 Evidence Pack 之上执行多阶段 AI 编排。
- 验证模型审计包含阶段名、provider、model、prompt hash、耗时、token 和重试信息。
- 验证模型失败时不会影响每日复盘主流程，会回退确定性报告并保留失败审计。
- 验证每日复盘 AI 配置复用全局 AI provider/model/base URL/API key env var/thinking/timeout。

## 已验证用例

| 用例 | 结果 | 说明 |
| --- | --- | --- |
| Fake LLM 五阶段成功 | 通过 | 生成 AI Markdown 和 AI 观察计划，审计包含五个阶段 |
| Fake LLM 首阶段失败 | 通过 | 报告状态为 `partial`，保留确定性观察计划，写入失败审计 |
| 全局 AI 配置复用 | 通过 | `zhipu` 归一化为 `glm`，复用 45 分钟复盘超时和 thinking 设置 |
| 未配置 API key | 通过 | orchestrator 不创建，UI 勾选后走确定性兜底并记录 skipped |
